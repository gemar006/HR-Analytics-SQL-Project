# HR Analytics SQL Project

## Overview

This project analyzes employee data using SQL Server to generate meaningful HR insights. The dataset contains employee information such as department, salary, attendance, performance rating, experience, gender, age, and attrition status.

The objective of this project is to identify workforce trends, employee attrition patterns, salary distribution, attendance performance, and departmental statistics to support data-driven HR decision-making.

## Tools Used

* SQL Server
* T-SQL
* Microsoft Excel
* GitHub

## Dataset Columns

* Emp_ID
* Employee_Name
* Gender
* Age
* Department
* Designation
* Salary
* Experience_Years
* Attendance_Percent
* Performance_Rating
* Attrition

## Key SQL Analysis Performed

### Employee Overview

* Total Employee Count
* Department-wise Employee Distribution
* Gender Distribution
* Age Group Analysis

### Attrition Analysis

* Overall Attrition Rate
* Department-wise Attrition Count
* Department-wise Attrition Rate
* High-Risk Employee Identification

### Salary Analysis

* Average Salary by Department
* Highest and Lowest Salary by Department
* Top 10 Highest Paid Employees
* Salary Band Classification
* Department-wise Salary Ranking

### Performance Analysis

* Employees with Highest Performance Rating
* Performance vs Attendance Analysis
* Performance vs Salary Analysis

### Experience Analysis

* Department-wise Average Experience
* High Performing Experienced Employees

### Advanced SQL Concepts Used

* Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)
* CASE Statements
* Window Functions

  * RANK()
  * DENSE_RANK()
  * ROW_NUMBER()
* Common Table Expressions (CTE)
* GROUP BY
* ORDER BY
* Conditional Aggregation

## Key Insights

* Employee attrition trends were identified across departments.
* Salary distribution varies significantly between departments.
* Higher attendance is generally associated with better performance ratings.
* Certain employees were identified as potential attrition risks based on salary, attendance, and experience.
* Department-wise rankings helped identify top performers and highest-paid employees.

## Conclusion

This project demonstrates practical SQL skills used in real-world HR analytics. Through data exploration, aggregation, ranking functions, and attrition analysis, meaningful business insights were generated to support workforce planning, employee retention strategies, and performance management.
